About Luck's Mango

Luck's Mango는 신발과 가방을 중심으로 시작한 빈티지 셀렉트샵입니다. 현재는 의류까지 확장하며, 브랜드·상태·가격뿐 아니라 사람과 상황, 스타일의 의미를 함께 살피고 있습니다.

```

중고 제품을 단순히 다시 판매하는 것이 아니라, 어떤 사람이 어떤 상황에서 왜 이 물건을 선택하는지 연구합니다.

```

Research Lab

럭스망고 연구실은 물건과 사람 사이의 연결을 기록하는 공간입니다.

```

현재 연구 질문

왜 스키니진은 유행이 지났는데도 여전히 선택될까?
하이라이즈 데님은 무엇을 강조하고 무엇을 보완할까?
신발과 가방은 왜 의류보다 직관적으로 사입이 가능할까?
남성복은 왜 여성복보다 Context를 읽기 어려울까?

분석 프레임

Product Feature → Style → Context
User → Context → Goal → Pain → Solution

```

Buying Diary

사입일지는 오늘 어떤 물건을 샀는지보다, 왜 샀고 왜 사지 않았는지를 기록하는 공간입니다.

```

예시

상태가 좋은 구두라도, 뒷축 실밥이나 접착 상태가 불안하면 사입하지 않습니다. 좋은 물건은 브랜드만으로 결정되지 않습니다. 사용될 상황, 상태, 고객이 받을 경험까지 함께 판단합니다.

```
